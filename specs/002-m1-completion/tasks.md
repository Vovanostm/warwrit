## Format and Path Conventions

Это единственная исполняемая очередь завершения M1. Выполненные задачи отмечены ниже.
ID последовательно назначены по фазам семи историй активной спецификации.
Прежние ID из пакета 001 сопоставлены с текущими в его [указателе](../001-warwrit-m1/tasks.md).
Пути ниже отсчитываются от корня репозитория. Запись результата, доказательства,
ограничения и следующий шаг принадлежат указанному рабочему пакету.
Его результат и checkbox этой очереди обновляются вместе.

Перед изменением исходников воспроизвести конкретный пробел и использовать
совместимые готовые части. Сохранять Node 24/pnpm, TypeScript, Fastify,
PostgreSQL/Kysely/pg, React/Vite и Babylon.js из плана. Адресные регрессии
покрывают риски из спецификации. Общие CI/full suites следуют AGENTS.md.
Каждый завершённый срез проходит обычный вход, прямую проверку, запись
у владельца, короткий CHANGELOG и отдельный коммит с сохранением чужой работы.
