## Outcome and boundary

Open `mill.html` on the existing web development server to inspect the complete
generated ruined-mill battlefield. Retain source/3D, day/night, orbit/zoom/pan,
close/reset and elevation controls. The runtime uses Babylon.js and embedded GLB
textures. Keep the current game's default entry and combat rules unchanged.

Ship `scene-3d-refinement` with registered clay/albedo inspection, a reproducible
1K probe, selective projection, interrupted-run protection and correct examples.
The exact one-material `source-geometry.glb` travels with the retained paint so
fresh clones can reproduce the workflow without the original local commit.
All scripts use installed Blender/AssetFurnace; no model weights are included.

## Acceptance for this delivery

- The standalone viewer loads the transferred asset and its controls work.
- Skill commands reference tracked inputs; preparation, projection and packing
  preserve the original geometry and reject unfinished projection batches.
- Existing scoped script evidence remains applicable where source is unchanged;
  verify changed paths and the current integrated viewer. Independent source
  review and applicable clean-checkout CI must pass before normal merge.
- Preserve provenance, historic failures and current limits. Material clarity
  passed at 2/2; full-scene art remains REJECT for rendering, night hierarchy and
  wheel/bank integration. This delivery does not claim production art acceptance.
