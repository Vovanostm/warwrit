## Scope

Dependency-free serializable company types, exact integer money/time, immutable finite definition catalogue, forty-three discriminated command payloads and strict input/actor/source guards. Protocol contains transport-only DTOs and does not import domain behavior. Existing M0 rules and replay are untouched.

Success from `parseCompanyCommand` means shape, finite references and listed context-free predicates only. `guardCompanyCommand` additionally verifies the supplied authenticated adapter context. Neither executes gameplay. `executeCompanyCommand` explicitly rejects even a valid request with `UNSUPPORTED_ACTION` and returns the identical input state until handlers are introduced in later slices.

There are no endpoints, database migrations, payroll, recruitment lifecycle, succession reducer, world simulation, UI or V2 combat implementation in this slice.

## G0 reconstruction

The foundation edition is independently reconstructed from the live Notes named in `WP-02.1-SOURCES.json`; it is not the bytes of either earlier ZIP. Catalogue version `s02-foundation-catalogue-1` and command schema `urn:warwrit:company-command:foundation-1` identify this representation. `s02-domain-provisional-0.2` identifies the source policy profile, not a claim that all its reducers exist.

The catalogue contains the eight enabled skills plus a disabled fixture, 32 perks, six origins, fifteen items, three works and four conditions supported by the read Notes. External culture, location, appearance-service and provider catalogues are not invented. Those IDs require trusted context and later handlers. Cosmetic patch keys and kernel event data remain bounded raw data, not falsely typed executable changes. All handlers fail closed.

Optional fields must be omitted rather than supplied as null in this edition. JSON numbers are finite and integers are safe; exact money and ticks use canonical decimal strings. Resource limits are technical boundaries, not gameplay caps. Date-of-birth offsets may be negative; duration/current campaign ticks and money may not.

Missing archive concordance remains `RC-GAP-MACHINE-01`. This slice does not claim all 117 expected full-domain scenarios are mapped or executed. Add actual source-to-test mappings rather than manufacturing case IDs.

## Trust and determinism

An actor string in a payload is not authorization. A trusted adapter must bind account/company/world and principal. Every non-player request needs an adapter-verified grant bound to command ID, source ID and full canonical request content. PLAYER expectedRevision refers only to the observed public projection. Canonical revision stays in trusted context. Fresh-revision checks are separate so durable retry lookup can precede CAS in WP-02.7.

The JSON schema exported from the same input registry describes transport shape, not authorization or all cross-record predicates. Parser output is a detached frozen copy; exported catalogue and schema registries are immutable. Bounded JSON rejects non-data values and accessors. The core performs no I/O or ambient time/random reads.
