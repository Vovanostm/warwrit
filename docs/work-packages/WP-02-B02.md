# WP-02 B02 — finite perk effect evaluator

B02 is a pure `game-core` calculation over the B01 selected-perk source, the canonical catalogue and actual equipped item state.

It returns detached, JSON-safe snapshots for holder additive effects, finite CARE/STUDY/TRAINING modifiers and the single lifecycle effective-leader morale contribution. Weapon-discipline effects require a complete matching actual equipped profile; defense remains personal. BPS values are retained as exact rational BPS (`numerator / denominator`) with identity `10000 / 1` and no intermediate rounding.

B02 does not execute care, learning, retraining or combat projection and does not add a root field, command, receipt or generic effects framework. B03/C/G remain the owning consumers.
