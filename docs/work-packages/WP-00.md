# WP-00 — Repository & Engineering Foundation

- Status: Implemented by pull request
- Priority: P0
- Milestone: M0 — Headless Combat Proof
- Requirements: `ENG-FND`, `ARCH-BOUNDARY`

## Mission

Create a reproducible monorepo, CI, and enforceable architecture boundaries without implementing gameplay functionality.

## Scope

- pnpm workspace;
- `apps/web` and `apps/server`;
- `packages/game-core`, `packages/protocol`, and `packages/testkit`;
- strict TypeScript settings;
- formatting, linting, type checking, build, and unit CI;
- Docker Compose PostgreSQL;
- ordered up/down migrations and smoke test;
- structured server logging;
- liveness/readiness endpoints;
- source and asset validation skeleton;
- root `AGENTS.md` and authority documentation.

## Non-scope

- gameplay mechanics or balance;
- tactical battle UI;
- authored production content;
- microservices, Kubernetes, distributed queues, or multi-region deployment.

## Evidence

- Clean-checkout command: `./scripts/bootstrap.sh`.
- Linux gate: `.github/workflows/ci.yml`.
- Deterministic-core boundary: ESLint policy plus `scripts/check-architecture.mjs`.
- Dependency-cycle detection: repository architecture check.
- Transactional migration up/down: `scripts/migration-smoke.ts`.
- Reproducible dependency graph: committed `pnpm-lock.yaml`.
- Health and structured logging: `apps/server/src/app.test.ts`.
- Project authority: `docs/authority/PROJECT_AUTHORITY.md` and `AGENTS.md`.

## Exit gate

WP-00 closes only after the pull request is green and the repository can be reproduced from a clean Linux checkout. Completion does not unblock implementation of WP-01 until the Combat Core design session resolves its separate design blockers.
