| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Parent              | Product manager/coordinator: creates tasks, checks design/results and delegates; owns shared resources, integration/publication, final evidence audit and acceptance | Does not personally implement or reproduce every worker check; only parent transfers write ownership or authorizes delivery |
| Luna (`gpt-6-luna`) | First implementation hands for bounded slices and executor of focused verification                                                                                   | One writer per slice/path, named checkout and resources; reports exact revision, results and limits                         |

The checked-out `.codex/config.toml` requests a target ceiling of **12 spawned agents per session**, excluding the primary. The planned mix is 10 Luna and 2 Sol; a spawned Astra orchestrator consumes one of those same 12 slots and must replace a Luna or Sol slot. The primary Astra is outside that spawned-agent count. The config sets Luna/high as the default; the implementer is explicitly Luna/high, the reviewer Sol/high, and the read-only orchestrator Astra/high. This is prepared project configuration, not evidence that the running host loaded it or can sustain the target. The observed live budget remains **parent plus two active workers total**, including any noninteractive CLI worker. Do not add work until the parent confirms a newly launched session actually exposes the requested capacity. Configuration changes do not retroactively enlarge this session. Native launches have intermittently failed and later succeeded; completion does not prove release. The CLI is replacement capacity when native dispatch is unavailable, not additional capacity. Preserve actual sandbox/process evidence; a copied role prompt is not native profile loading. No measured throughput gain: `NOT_MEASURED`.

Use the [parallel queue](PARALLEL_WAVES.md) for current owners, paths, dependencies, and handoffs; use [CURRENT_PLAN](CURRENT_PLAN.md) for the active checkout, evidence, and authority. Before implementation, the producer and consumer agree on the typed request, response, failure statuses, and owner of any shared mount/barrel. Workers communicate API and path changes directly to affected owners and copy the parent on decisions or blockers. Each worker acknowledges the assignment, keeps one writer per path, and returns one focused evidence packet. Sol performs independent read-only review on a frozen, meaningful batch; a later edit invalidates only evidence affected by that edit. Do not create one PR per card: the parent integrates related cards when their boundaries and proof are reviewable. Shared barrels, migrations, app mounting, lockfile, DB, and browser lifecycle need named ownership. Do not start extra work without an explicit capacity assignment.

Keep updates event-driven: report a dependency change, reproducible blocker, completed verification, or required decision rather than interrupting the parent with routine polling. Each completed packet records start/end UTC, exact revision and evidence links, whether an accepted playable result was reached, blocked time only when observed, and independent review returns. Historical timing without those observations is `NOT_MEASURED`; parallel-agent throughput or an optimal team size remains `NOT_PROVEN` until comparable work is measured.

Implementation, tests and checked mission PR merges are authorized within the owner's M1 assignment. Auto-merge, deployment, paid provisioning and force-push are not. A role or a green branch cannot grant acceptance, external-write authority or a merge. Parent verifies the exact union using the final sequence owned by [AGENTS.md](../../AGENTS.md#verification-without-duplicate-work) and `scripts/bootstrap.sh`, applicable CI `check:changes`, and actual-main readback.
