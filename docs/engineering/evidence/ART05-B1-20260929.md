the repository root:

```sh
pnpm --filter @warwrit/renderer-spike exec vite --host 127.0.0.1 --port 5182 --strictPort
```

If the parent-owned5182 service is already running from this worktree, reuse it.
Open `http://127.0.0.1:5182/?engine=playcanvas&art-preview=sprite`. Select Day and
compare the static rear-left Knight with surrounding miniatures; select it and a
neighbor, then select Night. This is an art diagnostic, not the alpha launcher.
