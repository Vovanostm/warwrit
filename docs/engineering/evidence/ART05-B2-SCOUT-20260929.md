## Behavior and corrections

The existing bake scene selects red Knight, Rogue or Barbarian, one of `Idle_A`,
`Walking_A`, `Melee_1H_Attack_Chop`, `Hit_A`, and an explicit sample in seconds.
Idle/Walking use a half-open clip interval; Attack/Hit include the exact endpoint
without looping. Equipment is calibrated once at the evaluated Idle reference
pose, then retains its local attachment through the selected animation. No game
state, normal scene controller or static sprite consumer is introduced here.

The first candidate lost actor/direction/pass identity in its browser adapter;
the actual generator rejected direction zero. Review also found that per-sample
world orientation cancelled weapon rotation. Parent browser samples reproduced
that behavior. The corrected adapter retains identity and fixes local attachment
calibration. A separate rendered Rogue check found the upward dagger lay along
its forearm; its reference orientation now points the blade below the hand.
General animation bytes are hashed as a reference-pose input even when the
selected clip comes from Movement or Combat.

## Reproduce the finite scout on this machine

Use the repository-pinned Node 24.20 / pnpm 11.25, frozen dependencies and installed
Chrome. From this checkout, start a free parent-owned port:

```sh
pnpm --filter @warwrit/renderer-spike exec vite --host 127.0.0.1 --port 5183 --strictPort
```

In a second terminal at the same checkout:

```sh
export WARWRIT_PLAYWRIGHT_CLI=/Users/vovanostm/.npm/_npx/31e32ef8478fbf80/node_modules/@playwright/cli/playwright-cli.js
export WARWRIT_ART_BAKE_URL='http://127.0.0.1:5183/?engine=playcanvas&art-bake=1'
node apps/renderer-spike/scripts/bake-art-assets.mjs --scout --actor=Knight --clip=Melee_1H_Attack_Chop --sample-seconds=0.5333333611488342
node apps/renderer-spike/scripts/bake-art-assets.mjs --scout --actor=Rogue --clip=Walking_A --sample-seconds=0.5333333611488342
node apps/renderer-spike/scripts/bake-art-assets.mjs --scout --actor=Barbarian --clip=Hit_A --sample-seconds=0.6666666865348816
```

The CLI path was verified on this machine; other machines must point the variable
to their installed Playwright CLI. The explicit scout flag writes only beneath
`scout-b2/<actor>-<clip>-t<seconds>`. The no-argument path retains its original
ART05-A target and should only be regenerated intentionally. Inspect front/side
views and the normal/depth files before accepting a new time selection. This
scout is not the final animation sampling decision: fast/extreme intermediate
poses, the full corpus, animated consumers and matched renderer comparison remain.
