## Reproduction

Use the pinned toolchain and frozen dependencies. From this checkout:

```sh
pnpm --filter @warwrit/renderer-spike exec vite --host 127.0.0.1 --port 5184 --strictPort
```

Reuse the existing parent-owned service when it is already running. Open
`http://127.0.0.1:5184/?engine=playcanvas&art-animated=1`, choose Day, select a
Knight and observe the repeated walk; choose Night to compare prelit sprites and
lit miniatures. Remove `art-animated=1` to restore the miniature diagnostic.
This command is not the full-game launcher.
