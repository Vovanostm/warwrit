# Shared work-package contract

[AGENTS.md](../../../../AGENTS.md) owns current engineering rules.
[Spec Kit](../../../../specs/001-warwrit-m1/spec.md) and
[ROADMAP](../../ROADMAP.md) own scope, execution order and navigation.

Each package defines the player goal, normal entry, choices, alternative outcomes,
refusal, retry and saved consequences. Assign one writer per shared path.
Verify affected behavior and concrete risks. Independent critique, CI and broad
checks follow AGENTS.md.

Keep current results in the feature document. Git retains earlier revisions.
Verify merge, deploy and paid-resource authority for the concrete mission.
