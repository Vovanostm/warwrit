# B6 — localization

[Localization rules](../../../wiki/world/localization.md) own string keys,
parameters and language-sensitive behavior. Existing accepted RU/EN catalogues
and fixtures retain their language contract.

The [Shield opening](../../../wiki/onboarding-book.md) has accepted RU/EN text.
The owner-approved [eleven new M1 quests](../../../wiki/economy-quests/m1-quest-texts.md)
use Russian; translation requires a separate owner request.

A selected localization change verifies the actual string consumers, interpolation,
plural/gender forms and language choice through the normal interface.
Record evidence in its feature document under [AGENTS.md](../../../../AGENTS.md).
