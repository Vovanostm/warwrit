# Доступность способностей

Кампанийные способности открываются по принятому профилю
[обучения](character-progression.md). Условия курса, завершения и прерывания
определяет [N06](../work-packages/m1-next/06-company-capabilities.md).

## Локальные команды sprite v3 — 2026-10-13

Стенд использует пять конечных приёмов: «Упор щитом», «Удар по броне»,
«Дальний укол», «Прицельный выстрел» и «Собраться».
Ранги 1–3 задаются редактором перед боем. Стоимости и эффекты находятся
в [локальном профиле](battlefield-test-maps.md#локальные-приёмы).
Предпросмотр, UI и AI используют одну исполняемую версию правил.

Подключение способности к кампании проверяет её действительный источник
изучения и совместимость сохранений. Доступность в редакторе определяется
настройкой конкретного тестового состава.
