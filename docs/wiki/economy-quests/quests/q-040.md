# Q040 След последней партии

**Авторское предложение, не действующий контракт M1.** V Кризисная. Уникальная история. Полная награда: **440 крон**, новый пробный баланс; обеспечена заранее, один раз одному законному предъявителю. Частичные выплаты не определены.

## Текст для игрока — авторский вариант

Рыночный распорядитель Каменного Брода собирает записи с совпадающими датами в одну стопку. Компания вытаскивает из неё последнюю передачу: рядом есть объём и подпись, но связь с остальными ещё предстоит проверить.

— Скажу всем, чьи партии здесь, — говорит распорядитель. — Они ждут ответа.
— Что скажете про эту? Кто передал и кому — мы ещё не сверили.

Распорядитель оставляет лист отдельно.

— Тогда с него начните. Если я ошибаюсь, мне людям объяснять. Но ждать своего они тоже бесконечно не могут.

Он показывает полученные отчёты о расписке и испорченной партии. В них можно найти основания проверки; одинаковая дата пока остаётся только датой.

**Журнал:** проверить передачу сравниваемых партий в двух местах, установить причину пропаж и решить, кому сообщить доказанное.

**Узкому кругу:** распорядитель садится с участниками возврата. Остальные этого разговора пока не слышали.

**Затронутым сторонам:** компания разбирает записи по их вещам. Каждый получает свой ответ и может решить, с кем работать дальше.

**Неполная версия:** распорядитель возвращает несвязанный лист на стол. «Вот это пока оставим открытым».

Распорядитель находит в законченном отчёте ту партию, о которой его спрашивают. Читает только относящуюся к ней часть, придерживая остальные листы. «Вот чей товар. Вот через чьи руки прошёл». Теперь он может ответить на этот вопрос, не начиная со слов «говорят, будто».

## Авторские условия

### Завязка и заказчик

**Встреча:** Рыночный распорядитель Каменного Брода. **Условие появления:** Несколько снабженческих расследований дали совместимые доступные сведения.

**Задача:** Установить подтверждённый источник региональных пропаж.

### Путь и выбор

Сопоставить реальные партии; пройти два доступных узла; получить доказательства передачи; представить результат.

**Развилка:** Сообщить узкому кругу для возврата имущества либо уведомить всех законно затронутых получателей: быстрый расчёт против более широких местных последствий.

### Результат и цена ошибки

**Доказательство полного успеха:** Реальные цепочки конкретных партий; единая версия не выдумывается из совпадения дат.

**Последствия:** Местные договоры меняются у осведомлённых; не возникает новая фракция/революция.

**Неуспех/задержка:** Недостаток общего доказательства оставляет часть версии открытой, не превращает любого участника в виновного.

### Повторение и связи

**Позднее участие:** читает доступный итог. Если имущество ещё требует отдельного возвращения или поставки замены, работа возможна на новый бюджет; за пересказ законченного расследования награды нет. Сцена выше показывается только при известном соответствующем исходе; реплика о незавершённой работе — только при её наличии.

Уникальный итог; открывается только после Q032 и Q038, без требования одного исхода.
