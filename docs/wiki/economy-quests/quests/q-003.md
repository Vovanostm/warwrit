# Q003 Гвозди для гати

**Авторское предложение, не действующий контракт M1.** II Обычная. Повторяемое при новом причинном событии. Полная награда: **65 крон**, новый пробный баланс; обеспечена заранее, один раз одному законному предъявителю. Частичные выплаты не определены.

## Текст для игрока — авторский вариант

— Гвозди у меня есть. Теперь нужны люди, которые донесут их до берега.

Кузнец Каменного Брода предлагает поднять ящик прежде, чем обещать один рейс. Железо удобно считать, неудобно нести. В Тихой Гати крепежа ждут для повреждённого настила.

**Журнал:** доставить весь крепёж на склад береговых работ; выбрать один тяжёлый или два согласованных лёгких рейса через доступную переправу.

**Один рейс:** ящик принят целиком. Компания меньше времени провела в пути, но несла полную нагрузку.

**Два рейса:** после второй выдачи склад получает тот же объём. «Теперь хватает», — говорит получатель, сверяя остаток. Людям было легче, припасов ушло больше.

**Неполная доставка:** уже принятое оставляют у работ. Не хватает крепежа, а не отметки в списке. Сам ремонт ещё впереди.

## Авторские условия

### Завязка и заказчик

**Встреча:** Кузница Каменного Брода → местный заказчик Тихой Гати. **Условие появления:** Существующий настил требует крепежа.

**Задача:** Привезти крепёж к береговым работам.

### Путь и выбор

Оценить груз; выбрать доступную переправу; доставить на место работ.

**Развилка:** Один тяжёлый рейс либо два разрешённых договором лёгких рейса: меньше риск переноски, больше времени и расходов.

### Результат и цена ошибки

**Доказательство полного успеха:** Полный объём принят на складе работ; каждый рейс учтён один раз.

**Последствия:** Запасы для ремонта доступны; настил меняется только после отдельной работы.

**Неуспех/задержка:** Приход к воде без доступного перехода не завершает доставку.

### Повторение и связи

**Новая работа:** Новая нужда другого участка настила и бюджет. Независимая обеспеченная причина может дать отдельный заказ сразу; старый источник не сбрасывается.

**Что требуется до реализации:** Собственные участники и проверяемые входы/результаты; [границы внедрения](../sources.md). Передача партии/альтернативному получателю не реализована текущими тремя M1-шаблонами.
