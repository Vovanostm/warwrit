# Q037 Залог на два имени

**Авторское предложение, не действующий контракт M1.** III Опасная. Повторяемое при новом причинном событии. Полная награда: **105 крон**, новый пробный баланс; обеспечена заранее, один раз одному законному предъявителю. Частичные выплаты не определены.

## Текст для игрока — авторский вариант

Две квитанции обещают один хранимый предмет двум людям. Рыночный распорядитель Каменного Брода не отдаёт его на голосование.

— Каждому хочется забрать сегодня. Мне нужно знать, кто передал вещь и на каком основании. Давайте по порядку.

**Журнал:** проверить происхождение предмета, обе квитанции и последовательность передач.

**Общий разговор:** обе стороны получают относящиеся к ним основания; договориться проще там, где они согласны с установленным.

**Распорядитель хранения:** сведения сначала получает он и рассматривает выдачу в своём круге полномочий.

**После подтверждения:** предмет передают одному имеющему право получателю. У второго остаётся установленное требование либо опровергнутая претензия.

**Неполная цепочка:** согласие присутствующих не устраняет право отсутствующего владельца. Вещь не раздваивается для удобного примирения.

## Авторские условия

### Завязка и заказчик

**Встреча:** Рыночный распорядитель Каменного Брода. **Условие появления:** Две стороны заявили право на конкретный хранимый предмет.

**Задача:** Проверить последовательность передачи предмета.

### Путь и выбор

Осмотреть происхождение; сопоставить две квитанции; проверить настоящий момент передачи.

**Развилка:** Сообщить обеим сторонам проверенное основание или представить его действительному распорядителю хранения: открытое согласование против местного рассмотрения.

### Результат и цена ошибки

**Доказательство полного успеха:** Один предмет и связанная последовательность реальных передач.

**Последствия:** Хранитель отдаёт предмет только законному получателю; не создаётся копия для компромисса.

**Неуспех/задержка:** Согласие сторон не отменяет прав отсутствующего владельца.

### Повторение и связи

**Новая работа:** Новый отдельный спор о другом предмете. Независимая обеспеченная причина может дать отдельный заказ сразу; старый источник не сбрасывается.

**Что требуется до реализации:** Собственные участники и проверяемые входы/результаты; [границы внедрения](../sources.md).
