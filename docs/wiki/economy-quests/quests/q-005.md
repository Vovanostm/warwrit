# Q005 Еда для полевых работ

**Авторское предложение, не действующий контракт M1.** II Обычная. Повторяемое при новом причинном событии. Полная награда: **80 крон**, новый пробный баланс; обеспечена заранее, один раз одному законному предъявителю. Частичные выплаты не определены.

## Текст для игрока — авторский вариант

В амбаре Каменного Брода отложены шесть рационов для Северного Двора. Старейшина может принять их в общий запас или передать согласованной группе полевых работников.

— У склада свои нужды. У тех, кто выйдет работать, — свои. Решите, куда везёте, пока пища здесь.

**Журнал:** доставить все шесть рационов выбранному из договорного списка получателю; чужую еду не расходовать в пути.

**Общий склад:** кладовщик пересчитывает упаковки. Резерв деревни вырос; полевая группа ещё ждёт своей выдачи.

**Работникам:** получатель принимает пищу для группы. Можно готовить её выход на работу, но в общем амбаре эта поставка не появилась.

**Недовоз:** получатель отмечает число принятых рационов. Остаток остаётся отдельной нуждой; обещанная награда за полный груз не становится платой за часть.

## Авторские условия

### Завязка и заказчик

**Встреча:** Амбар Каменного Брода → старейшина Северного Двора. **Условие появления:** Резерв города допускает отпуск; деревне нужна пища.

**Задача:** Передать шесть рационов деревне.

### Путь и выбор

Узнать причину нехватки; принять груз; выбрать получателя из разрешённого договора списка.

**Развилка:** Отдать весь груз общему складу либо согласованной группе полевых работников: склад даёт широкий резерв, работники скорее возвращаются к текущему труду.

### Результат и цена ошибки

**Доказательство полного успеха:** Шесть рационов приняты разрешённым получателем, а не съедены компанией.

**Последствия:** Меняется запас выбранного получателя; другой остаётся без этой поставки.

**Неуспех/задержка:** Расход чужой еды в пути оставляет фактический недовоз.

### Повторение и связи

**Новая работа:** Новая оплаченная потребность без нарушения минимального резерва. Независимая обеспеченная причина может дать отдельный заказ сразу; старый источник не сбрасывается.

**Что требуется до реализации:** Собственные участники и проверяемые входы/результаты; [границы внедрения](../sources.md). Передача партии/альтернативному получателю не реализована текущими тремя M1-шаблонами.
