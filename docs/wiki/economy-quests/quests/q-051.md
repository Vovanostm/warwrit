# Q051 Две подписи один запас

**Авторское предложение, не действующий контракт M1.** II Обычная. Уникальная история. Полная награда: **50 крон**, новый пробный баланс; обеспечена заранее, один раз одному законному предъявителю. Частичные выплаты не определены.

## Текст для игрока — авторский вариант

У старейшин Березняка и Северного Двора две подписанные записи на один запас. Старейшина Березняка предлагает положить их рядом и отметить доли прямо возле обещанных объёмов.

— Отдадим каждому часть. Хоть что-то начнём сейчас.
— С частью я пока не знаю, что начну, — отвечает старейшина Северного Двора. — На весь объём рассчитывал. Сначала выясним, кому он обещан первым.

Компания просит показать сам запас и основание владения. Предложенные доли можно принять лишь с согласия того, кому принадлежат вещи. Старейшина Березняка убирает руку от своей записи и ждёт ответа владельца.

**Журнал:** проверить право на запас; выполнить согласованный раздел либо передать его по первоочередному праву.

**Раздел:** каждый получает записанную долю. Принимающие считают своё; недостающие объёмы остаются нуждой их работ.

**Приоритетное право:** один получает весь предусмотренный запас. Другой оставляет свою заявку: ему ещё нужно найти и оплатить другую партию.

**После передачи:** записи сверяют с тем, что люди унесли. Спор об этом запасе закончен; ожидание другого товара осталось у того, кто его не получил.

У старейшины лежит принятое соглашение. Он прикрывает ладонью первоначальные обещания и оставляет на виду исполненное: «Смотрите сюда. Вот что люди действительно получили». Когда руку убирает, видна разница между обещанным и переданным. Её больше не пытаются заполнить разговором.

## Авторские условия

### Завязка и заказчик

**Встреча:** Старейшины Березняка и Северного Двора. **Условие появления:** Одну законную партию обещали двум работам, это подтверждено.

**Задача:** Установить реального владельца и исполнить допустимое решение спора.

### Путь и выбор

Сверить обе подписи, право владельца и физический запас; до принятия закрепить допустимый раздел с долями либо передачу по приоритетному праву; выполнить выбранные передачи. Последующая вторая поставка принимается отдельно, только если её действительно выбрали и обеспечили.

**Развилка:** Полный результат 50 крон: разделить старый запас с согласием владельца и всех уполномоченных сторон по закреплённым долям либо передать его по приоритетному праву. В первом пути каждый получает меньший согласованный объём; во втором иной потребности ещё нужен свой запас. Отдельная будущая вторая поставка не является условием основного результата.

### Результат и цена ошибки

**Доказательство полного успеха:** Для раздела — согласие владельца/уполномоченных сторон, закреплённые доли и физическая передача всего старого запаса по этим долям; для приоритетного исполнения — физическая передача единственного запаса имеющей право стороне. Новые входы обязательны только для действительно отдельно выбранной второй поставки; её будущее исполнение не требуется для полного результата основного договора.

**Последствия:** Одна работа может ждать; долг не исчезает от публичного соглашения.

**Неуспех/задержка:** Нельзя признать две копии товара или навязать владельцу компромисс.

### Повторение и связи

**Позднее участие:** узнаёт доступное соглашение. Если второй запас ещё надо привезти, это отдельная работа с другим источником и бюджетом; одна партия не размножается для новой компании. Сцена выше показывается только при известном соответствующем исходе; реплика о незавершённой работе — только при её наличии.
