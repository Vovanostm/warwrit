Заимствованных кадров и fallback-иллюстраций для текстовых историй нет.

| Тип              | Фактические поля (`?` означает необязательное)                                                                                                              |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Mission`        | `id`, `title`, `place`, `genre`, `brief`, `motif`: строки; `presentation?: 'text' \| 'partial'`; `scenes: Readonly<Record<string, StoryScene>>`             |
| `StoryScene`     | `title: string`, `art?: MissionArtId`, `lines: readonly StoryLine[]`, `finding?: string`, `choices: readonly StoryChoice[]`, `ending?: string`              |
| `StoryLine`      | `id: string`, `speaker?: string`, `text: string`, `when?: StoryCondition`                                                                                   |
| `StoryChoice`    | `id`, `text`, `to`: строки; `requires?: readonly string[]`, `when?: StoryCondition`, `grants?: readonly string[]`, `once?: boolean`, `unavailable?: string` |
| `StoryCondition` | `all?`, `any?`, `none?`: массивы строковых фактов                                                                                                           |
| `StoryStep`      | `scene: string`, `facts: readonly string[]`; история — массив снимков шагов                                                                                 |

Начало всегда `{ scene: 'start', facts: [] }`. Ключи `scenes` — адреса переходов,
`to` указывает на такой ключ. Конец определяется наличием `ending`, включая `''`;
непустая строка выводится дополнительным абзацем. У всех текущих концовок пустой
массив `choices`; читатель вместо выбора показывает повторный запуск. Имя `end*`
само по себе концовкой не делает. `presentation` описывает показ, не переходы;
режим `partial` поддержан типом, но сейчас ни одна история его не использует.

`when` проверяется по фактам последнего шага: все `all` должны присутствовать,
хотя бы один из `any` — присутствовать, ни один из `none` — не присутствовать;
эти три условия соединены И. Отсутствующее условие пропускает; `all: []` и
`none: []` пропускают, `any: []` не пропускает. Непрошедшие `when` строки и варианты
скрываются. `requires` содержит **посещённые ID сцен**, не факты: нужны все ID
в текущем пути. `once` запрещает вариант, если уже посещён его `to`, а не его
choice ID. Видимые варианты, не прошедшие `requires/once`, отключены и могут
показывать `unavailable`. Неверный choice ID, закрытый переход или неизвестный
`to` не меняют путь; неизвестная текущая сцена вызывает ошибку.

Успешный `advance` добавляет шаг с объединением прежних фактов и `grants`, без
дубликатов. Эти факты живут только на текущем пути; операции удаления факта нет.
Назад удаляет последний шаг, возвращая прежний снимок фактов и находок; дальнейший
выбор создаёт новую ветвь без фактов отменённого будущего. Сначала/повтор/смена
истории начинают с `start` и пустых фактов. `finding` попадает в журнал по уникальным
посещённым сценам, не создаёт факт. `StoryLine.id` входит в DOM-ключ
`mission.<story>.<scene>.<line>`; это ещё не готовый контракт локализации.

Для адаптации доступны сюжетные ID, узлы, порядок абзацев, говорящие, варианты,
локальные условия и выбранные иллюстрации с provenance. Деньги, раны и доверие
описаны прозой и/или локальными флагами: списаний, ранений и изменений отношений
компании модель не выполняет. В этом формате нет authoritative mutations,
сохранения кампании, версии схемы, миграций, идемпотентности или проверки допуска
компании к миссии. `requires/when` не заменяют campaign eligibility. React history
не является игровым сохранением; возврат назад не откатывает серверные операции.
Разработка такого контракта, production runner, payroll/care/world и shared runtime
в текущий цикл не входят.

Проверка передачи: чтение актуальных model/reader/catalog/art и всех девяти
модулей; сопоставление story IDs, концовок и art ключей — выполнено. Scoped Prettier,
`git diff --check` и ссылки на tracked локальные файлы — PASS. Handoff описывает формат; runtime не меняется, данные Саввы заменены отдельно.
Повтор полного bootstrap ради документации и прозы — NOT_RUN;
прежний результат остаётся историей опубликованной редакции. Проверки новой Саввы фиксируются в этом продолжении; CI нового head ведёт координатор.
