# Построение отряда

Игрок расставляет бойцов и выбирает их действия в пределах действительного
состава и права управления. Самостоятельные эффекты построения требуют
конкретного правила выбранного сценария. Текущие команды и их проверка
принадлежат контракту боя.

Требования к UI и редактору — [поле боя](../battlefield-test-maps.md).
Версии, кампания и приёмка — [M1-CAMPAIGN-BATTLE](../../work-packages/M1-CAMPAIGN-BATTLE.md).
