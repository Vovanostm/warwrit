# Зона контроля

**Статус:** Первый приоритет (решено 2026-10-08), правило не утверждено ·
**Слой:** бой · [← все механики](index.md)

## Суть

Боец с оружием ближнего боя держит соседние гексы. Кто уходит из этой
зоны, получает свободный удар. Из зоны контроля нельзя стрелять. Это
делает строй осмысленным, а бегство — опасным: «связанного» врага нельзя
просто обойти.

## Предлагаемое правило

1. Зону держит боец в сознании, с оружием ближнего боя, не в панике
   ([мораль](morale.md)).
2. Шаг из гекса, соседнего с врагом, в гекс вне его зоны вызывает
   **свободный удар** каждого такого врага по правилу [удара](melee.md).
3. Свободный удар не тратит ОД атакующего; один удар на уходящего за шаг.
4. Если свободный удар нанёс урон здоровью — кандидат: уходящий остаётся
   на месте, ОД и выносливость шага потрачены (Battle Brothers).
5. Из зоны контроля нельзя стрелять из [лука](ranged.md).
6. [Отход с поля](retreat.md) через зону контроля вызывает свободный удар.
7. Бесплотный противник и твари с особым профилем могут игнорировать
   зону — только по явному профилю ([противники](opponents.md)).

## Что видит игрок

Подсветку зон врагов при выборе пути; путь через зону помечен,
предупреждение «уход вызовет удар: Ратша, ожидаемо 14 по броне»
([предпросмотр](preview.md)).

## Связи

- [Ход](turn.md) и [ожидание](turn.md#ожидание): выжидать, пока враг
  войдёт в зону.
- [Строй](formations.md): стена копий бьёт уже на входе в зону.
- [Мораль](morale.md): бегущий из зоны получает удары; паникующий зону не держит.
- [Смещение](displacement.md): вытолкнутый из зоны не вызывает свободного
  удара (кандидат).
- [Оружие](weapons.md): копьё с дальностью 2 — кандидат на зону в 2 гекса.

## Ориентир и ошибка

- Battle Brothers: зона контроля — ключевое понятие тактики.
- Ошибка BB: зону плохо объясняет интерфейс. У нас она всегда видна.

## Нужно для реализации

Новая версия правил ядра; события `attack.resolved` с причиной
«свободный удар»; анимация реакции; тест детерминированности.

## Открытые вопросы

- Останавливает ли попадание уходящего.
- Сколько свободных ударов за ход может сделать один боец.
