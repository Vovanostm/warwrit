# Контракты

Контракт связывает действительного заказчика, фиксированные принятые условия,
цель, доказательство, допустимого предъявителя и выплату.
До боя в обычном контракте разрешён уход. Всю награду получает предъявитель,
трофей передаётся заказчику.

Точные переходы определяет [M1-CONTRACT-TERMS](../../work-packages/M1-CONTRACT-TERMS.md).
Список и моральные последствия определяет [M1-QUESTS](../../work-packages/M1-QUESTS.md).
FIRST HUNT имеет [отдельную политику](../m1-spec.md#10-ограниченная-политика-первого-first-hunt).
