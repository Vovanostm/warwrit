# История компании

История показывает сохранённые факты, доступные этой компании.
При возвращении отчёт «Пока вас не было» использует действительные события
прошедшего интервала. Условия отчёта задаёт
[M1-OFFLINE-REPORT](../../work-packages/M1-OFFLINE-REPORT.md).

Подробная летопись боя относится к этапу после M1.
