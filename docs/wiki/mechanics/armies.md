# Армии герцогств

Армии принадлежат герцогствам. Игрок управляет компанией наёмников.
Армии могут действовать параллельно, захватывать поселения и менять общий мир.
Часть битв разрешает администратор, часть — принятые простые правила.
Конкретное исполнение и сведения наблюдателя задаются задачей мира.

Источник — [направление игры](../vision.md#кризисы).
