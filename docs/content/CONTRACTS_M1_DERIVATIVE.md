## Limits and outstanding producers

This is content structure, not gameplay execution or a quest rules engine. A
scene outcome names source-slot conditions and a next scene or a finite terminal
kind. The validator checks structural reachability; it cannot prove a runtime
fact occurred or was lawfully observed. `PENDING` with an `ALWAYS` gate is a
fallback-shaped declaration, not an outcome selector. CT02 must resolve
authentic fact chronology and supersession, then select the applicable terminal
outcome. Static source-slot presence alone is not runtime outcome proof.

Future CT/WORLD/JOIN/knowledge/encounter/inventory/finance work must bind the
slots to authentic producers, actual local issuers, physical captive or trophy
custody and exact accepted terms. Ordinary payout coefficients can use a
versioned working profile where authorized; this static edition deliberately
does not select payout terms. The existing unresolved helper leave/kick,
cancellation and post-proof rights cases remain for the owning activation task.
Neither this document nor the catalogue answers them by implication.
