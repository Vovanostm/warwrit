# Карта, города и таверны

Запрос владельца 2026-11-09: «Давай больше references — и таверну и города.
Карту лучше возьми текущую, либо сделать 2 уровня — приближённая карта —
может имеет смысл в 3d, но это накладно — пока глобальная только растровая».

## Карта: два уровня

**Уровень 1 — глобальная карта.** Это текущий растровый атлас v6
([assets/art/world/porechye-atlas-v1/atlas-v6.png](../../assets/art/world/porechye-atlas-v1/atlas-v6.png),
4608×3072, 1,5625 м на пиксель). Его владеет [глобальная карта](../wiki/world/map.md).
Референсы ниже **не перерисовывают атлас**: атлас уменьшен до 1536×1024,
а поверх него Codex дорисовал только элементы интерфейса.

| Изображение                                | Что показывает                                                                                                                                                                                                        |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ![](images/map/m-01-global-overlay.jpg)    | Банда-жетон с намеченным путём, чужие банды, колонна армии, кольца состояния мест, туман по краям                                                                                                                     |
| ![](images/map/m-02-global-place-zone.jpg) | Зона поселения пунктиром с двумя точками входа на окраине и карточка места с кнопкой «Войти». Связано с [входом с окраины](../wiki/world/map.md#общая-зона-поселения-вместо-трёх-подходов--ux-предложение-2026-10-26) |
| ![](images/map/m-03-global-world-turn.jpg) | «Ход мира»: стрелки армий, параллельная битва, раненые и дезертиры на дорогах, «Занято», журнал с датами                                                                                                              |

Генератор немного сдвигает мелкие детали атласа. Для решений смотреть на
слой интерфейса, а не на рельеф под ним.

**Уровень 2 — приближённая карта (окрестности).** Источник — вырезка
атласа v6 1536×1024 вокруг Каменного Брода (x=1947, y=938). Три варианта
одной местности:

| Вариант                            | Изображение                                  | Цена                                                                                                               | Когда выбирать                                                                |
| ---------------------------------- | -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------- |
| A. Растр сверху, крупнее в ~3 раза | ![](images/map/m-04-zoom-raster-topdown.jpg) | Низкая: тот же конвейер, что у атласа, плитки по району                                                            | Рекомендуется первым: тот же вид, что глобальная карта, переход плавным зумом |
| B. Растр под углом                 | ![](images/map/m-05-zoom-raster-oblique.jpg) | Средняя: другой ракурс, нужны маски проходимости под перспективу                                                   | Если нужна «сцена прибытия»; хуже для точного перемещения                     |
| C. 3D-диорама                      | ![](images/map/m-06-zoom-3d-diorama.jpg)     | Высокая: рельеф, модели домов, свет; Babylon уже в стеке ([ADR-0006](../architecture/0006-m1-renderer-babylon.md)) | Позже, если растр упрётся в масштаб или камеру                                |

Рекомендация: глобальная карта — атлас v6 (растр); окрестности —
вариант A (растр) только для мест с работой; 3D — не сейчас. Решение
владельца не принято. Технические детали (зум, маски, переход между
уровнями) — задача [Map Editor](../engineering/UNIFIED_MAP_EDITOR.md).

## Ограничения

- На tw-02 (деревянная башня с крестом) и tw-07 (шпиль) модель добавила
  культовые постройки. Вера мира не задана — не использовать их как канон.
- m-05: роза ветров без букв, но в правом верхнем углу; на m-01 подписи
  мест не нарисованы.
- Городские сцены (кроме Каменного Брода) опираются только на строку
  из таблицы городов; география округов не сверена с атласом мира.
