# Референсы интерфейсов

Шестнадцать экранов, которые понадобятся банде наёмников в общем мире.
Для каждого: на какой вопрос игрока экран отвечает, какой приём у ориентира
работает, как он выглядит у нас и макет-референс. Макеты сгенерированы
([art.md](art.md)); надписи на них — заглушки, а раскладка — повод для
обсуждения, не утверждённый дизайн.

Общие правила, вытекающие из [DESIGN_COMPASS](../engineering/DESIGN_COMPASS.md):

- Один десктопный интерфейс; на телефоне — тот же в ландшафте, мельче
  ([AGENTS.md](../../AGENTS.md)).
- Всё, что влияет на решение, видно **до** подтверждения: цена, цель,
  причина отказа, известный риск. Предпросмотр = та же функция, что расчёт.
- Важное читается на миниатюре; текст коротких надписей — не длиннее 2–3 слов.
- Материал рамок — кожа, бумага, тушь; без геральдики и эмблем, пока владелец
  не утвердит знаки сторон.

## Чего избегать в интерфейсе

- Шанс, который врёт (XCOM 2); правило, видимое только после ошибки (зона
  контроля BB).
- Таймер «миссия провалена» вместо давления обстановкой: ночь, подкрепление,
  уход врага.
- Журнал заданий вместо летописи: игроку нужен мир, а не чек-лист.
- Отдельные портретные экраны для телефона: запрещено без решения владельца.
