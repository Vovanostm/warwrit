## Как пользоваться

1. Перед экраном, контрактом или сценой открыть нужную страницу и её образ.
2. Проверить идею по чек-листам [compass §5](../engineering/DESIGN_COMPASS.md#5-checklists).
3. Макет — повод для обсуждения: раскладка, надписи и персонажи на нём не
   утверждены. Новое правило или канон — только решением владельца.
