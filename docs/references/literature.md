# Книги и короткие детективы

Запрос владельца 2026-11-09: «Добавь больше произведений и детективов коротких
как референсы — посмотри популярные книги с хорошим рейтингом».

Отбор: высокий рейтинг читателей и прямая польза для Warwrit — моральный
выбор, расследование в замкнутой общине, жизнь отряда на войне. Рейтинги
взяты из поиска Goodreads 2026-11-09 (средняя оценка / число оценок).
Это сигнал популярности, а не мера качества: у русских изданий на Goodreads
мало оценок. Тексты не копируются; ниже — только приём и вывод для нас.
Фольклор, Гоголь, Пушкин, классическая проза и модули D&D уже разобраны в
[onboarding-references](../wiki/onboarding-references.md).

**Читать это не обязательно**: это не замена правилам
[Как писать](../wiki/world/writing.md). Тексты в стиле этих авторов не пишем.

## Как пользоваться

- Для схемы расследования брать форму Холмса или Марпл: 3–4 шага, одна
  странная деталь, вывод из быта.
- Для морального выбора проверять по [правилам](moral-choices.md#правила-моральных-выборов-в-warwrit):
  две знакомые жертвы, неполное знание, отложенное последствие.
- Не переносить сюжеты, имена, существ и узнаваемые развязки.
