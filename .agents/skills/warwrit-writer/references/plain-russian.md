# Словарь простых слов

Редкое или устаревшее слово → то, что чаще говорят сейчас. Названия мест
из канона (Тихая Гать, Каменный Брод) не меняются; непонятные должности
описываются («глава города» вместо «посадник»), «староста» остаётся.
Колонку «Корень» читает `scripts/check_text.py`: совпадение ищется с начала
слова, без учёта регистра. Корни через `/`; `$` в конце — только целое слово.

Известное ложное срабатывание: глагол «подать» («подать воды») — оставить.

Если сомневаешься, частое ли слово: выбери то, которое сказал бы
современный горожанин. Если такого слова нет — опиши предмет коротко.
