# ТЗ на текст квеста

Обязательный состав и размеры текста одного квеста Warwrit. Приёмы взяты
из устройства квестов «Ведьмака 3»
([разбор](../../../../.studioigor/research/witcher-quest-writing.md)):
маленькая работа оборачивается историей о людях, выбор серый, последствие
приходит позже.

## Что нужно до письма

| Вход                   | Откуда                                                      |
| ---------------------- | ----------------------------------------------------------- |
| Ключ `ci.m1.<slug>.01` | Задача квеста                                               |
| Шаблон                 | HUNT, INVESTIGATE или RESCUE                                |
| Размер                 | Малый (простая работа) или сюжетный/моральный               |
| Место и заказчик       | `places.csv`, `characters.csv`; новый человек — `proposal`  |
| Награда                | Задача квеста или черновик каталога                         |
| Рамка выбора           | Решение владельца, если квест моральный                     |
| Связи и порядок        | После каких квестов появляется; что из канона нельзя менять |

Нет входа — задай владельцу один вопрос, не придумывай.

## Блоки текста

| #   | Блок              | Требование                                                                                                                                 |
| --- | ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | Питч (для автора) | 2–3 предложения: кто просит, что случилось, в чём поворот                                                                                  |
| 2   | Заказчик          | Имя, место, дело. Чего хочет. **Не говорит** — одна вещь, которая потом сыграет                                                            |
| 3   | `brief` на доске  | Голосом заказчика: что случилось + что сделать. До 25 слов. Без условий выплаты                                                            |
| 4   | Сцена взятия      | 3–6 реплик. Заказчик говорит о своём, одна живая деталь, один вопрос игрока                                                                |
| 5   | Находки           | Малый: 1–2. Сюжетный: 3 — очевидная, двусмысленная, поворотная. Каждая — что видно или кто сказал                                          |
| 6   | Поворот           | Только сюжетный. Меняет смысл просьбы, понятен с первого раза, один на квест                                                               |
| 7   | Выбор             | Два действия игрока («Убить стаю» / «Рассказать Кондрату»). У каждого своя ценность и цена. Малый квест — практическая развилка с разницей |
| 8   | Исходы            | На каждую ветку и неудачу — сцена: ремарка с действием (1–2 фразы), 1–2 реплики, финал на детали. Последние фразы разные                   |
| 9   | Позже             | Сюжетный: сцена-факт, которую компания увидит в мире позже. Не пересказ, а вещь: колокол ночью, заколоченная дверь                         |
| 10  | Для дизайнера     | Таблица: шаблон, награда и кто платит, развилка, доказательство, что сохраняется, где видно, порядок                                       |

## Размеры

| Размер              | brief     | Сцена взятия | Находки | Поворот | Исходы                   |
| ------------------- | --------- | ------------ | ------- | ------- | ------------------------ |
| Малый               | ≤ 25 слов | 3–4 реплики  | 1–2     | —       | сцена на ветку + неудача |
| Сюжетный, моральный | ≤ 25 слов | 4–6 реплик   | 3       | 1       | сцена на ветку + «Позже» |

Реплика — обычно до 15 слов, не больше 18. Ремарка — 1–2 фразы.

## Шаблон

```markdown
### Название — `ci.m1.<slug>.01`

**Заказчик:** Имя, дело, место. **Не говорит:** одна вещь.

> **brief:** Что случилось. Что сделать.
>
> — Реплика заказчика.
> — Вопрос игрока?
> — Ответ с живой деталью.

**Находки:** «Что видно». «Кто что сказал».

**Ветка А.** Выплата или её нет.

> Ремарка: что человек делает.
>
> — Реплика.
>
> Позже: вещь, которую компания увидит в мире.

**Ветка Б.** …

| Для дизайнера   |                           |
| --------------- | ------------------------- |
| Шаблон, награда | шаблон; сумма; кто платит |
| Развилка        |                           |
| Доказательство  |                           |
| Сохраняется     |                           |
| Где видно       |                           |
| Порядок         |                           |
```

## Не входит в текст игрока

Условия выплаты, доказательства и повторяемость — только в таблице.
Механика (руки, узлы, шаги) — только если от неё зависит выбор.
Английский перевод — только по просьбе владельца.
