# Warwrit — ten directions, seven subjects

70 selected PNG illustrations (1536×1024), ten comparison sheets in `boards/`,
and the static `index.html` gallery. Open that file in a browser or serve this
directory locally; the gallery supports style/subject filters, zoom and grayscale.

The owner selected direction 02 as the main 2D style and direction 05 as an
explicit location/environment override. Current selected references and JSON
requests are in [the style directory](../../styles/README.md).

`prompts.json` retains exact prompt history. Discarded iterations and the large
local ZIP remain in the original author checkout and are not published. Historical
iteration inputs are not included, so the history is not a portable replay package.
These are concept studies, not runtime-integrated assets or new canonical lore.
